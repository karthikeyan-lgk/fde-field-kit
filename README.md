# FDE Field Kit labs

Labs for the **FDE Field Kit** series on the Observability Labs YouTube channel: forward deployed engineering, hands-on.
Each episode drops you into a fictional customer's system with no docs, read-only access and a deadline, and the only
tools you bring are zero-code ones: OpenTelemetry eBPF Instrumentation (OBI), the OpenTelemetry Collector, Jaeger,
Prometheus and Grafana.

| Episode | Lab | Videos |
|---|---|---|
